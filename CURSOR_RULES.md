# CURSOR RULES

## 🎯 PRIMARY RULE: ALWAYS EXPLAIN BEFORE EXECUTING

**BEFORE making any changes, modifications, or executing any code, the AI assistant MUST:**

1. **Explain exactly what was understood** from the user's request
2. **Detail the specific plan** of what will be done
3. **Ask for confirmation** before proceeding
4. **Only execute after user approval**

## Example Format:

```
## What I Understood:
[Explain the user's request in your own words]

## What I Will Do:
[Detail the specific steps/plan]

## Confirmation:
Should I proceed with [specific action]?
```

## Why This Rule Exists:

- Prevents misunderstandings
- Ensures user has full control
- Avoids unwanted changes
- Improves communication quality

## How to Use:

- Reference this file in future conversations
- Say "Remember the cursor rule" or "Explain before executing"
- Point to this file if the AI forgets the rule
